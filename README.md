# Flight Price Predictor

An end-to-end machine learning project that predicts airline ticket prices
using a Multilayer Perceptron (MLP) neural network, with an interactive
Streamlit web app.

##  Overview

- **Dataset:** 10,683 flight records with 11 attributes
- **Model:** Multilayer Perceptron (MLP) Regressor — 2 hidden layers of 128 neurons
- **Features used:** Airline, Source, Destination, Journey Day/Month, Departure
  & Arrival Hour/Minute, Duration, Total Stops
- **Metrics:** MSE = 0.0084, MAE = 0.0661, R² = 0.764

## 🛠️ Tech Stack

- Python 3.10+
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Streamlit
- Joblib
